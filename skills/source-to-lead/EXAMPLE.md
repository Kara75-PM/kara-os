# 이렇게 흘러갑니다 — 이야기 하나로 신청까지

> 이 문서는 **설명서가 아니라 구경거리**입니다.
> 이야기 하나를 주면 **어떤 표가 나오는지** 그대로 보여줍니다.
>
> 🔵 여기 나오는 사람은 **가상의 인물**입니다. 만든 사람의 실제 이야기가 아닙니다.
> 「앱을 만드는 3년차 기획자」가 처음 써본다고 가정했습니다.
>
> 📖 글쓰기 쪽 예제는 `../sns-writing/EXAMPLE.md` 에 있습니다. **같은 이야기로 이어집니다.**

---

## 이 스킬을 언제 쓰나

**글은 열심히 쓰는데 신청하는 사람이 없을 때.**

원인은 대체로 하나입니다.

> 글을 읽은 사람이 **「그다음에 뭘 해야 하는지」** 가 없습니다.

이 스킬은 **글을 쓰기 전에** 그것부터 정합니다.

---

## 0. 친 것은 이 한 줄

```
이 이야기로 콘텐츠 만들어줘.
"새로 깐 앱을 첫 화면에서 그냥 껐다"
```

**나온 것**

```
「이 이야기로 콘텐츠 만들어줘」는 source-to-lead 가 맡는 일이라 불러오겠습니다.

재료 폴더를 찾았습니다 — ~/내작업폴더/kara-os-private/
who-i-am.md 를 읽었습니다. destinations.md 는 없네요.

먼저 0단계부터 가겠습니다.
```

## 1. 0단계 · 어디로 보낼 건가 — **여기가 이 스킬의 전부입니다**

```
🔴 이 단계를 건너뛰면 이 스킬은 그냥 콘텐츠 스킬이 됩니다.

질문은 하나예요.

  이 이야기로 만드는 글들이 「결국」 사람을 어디로 데려가나요?

⚠️ 글 한 편마다 정하는 게 아닙니다. 「묶음 전체」의 도착지를 정하는 겁니다.

목적지는 두 종류입니다.

  🔗 링크형   주소가 있다   신청 폼 · 랜딩 페이지 · 오픈채팅 초대 링크
  🚪 자리형   주소가 없다   슬랙 댓글 · 쪽지 · 오프라인 모임

어느 쪽인가요? 아직 받을 곳이 없으시면 그것부터 만들자고 말씀드리겠습니다.
```

**이렇게 답했습니다.**

```
"앱 첫 화면 점검 체크리스트"를 무료로 주고 메일 주소를 받으려고 해.
구글폼으로 만들어뒀어.
```

**받은 답**

```
좋습니다. 정리하면 이렇습니다.

  목적지:   구글폼 (앱 첫 화면 점검 체크리스트 신청)
  종류:     🔗 링크형 — 주소가 있으니 꼬리표를 붙일 수 있습니다
  남기는 것: 메일 주소
  이번 목표: 몇 명으로 잡으실까요?

목표를 정해두면 7단계에서 "됐다/안 됐다"를 말할 수 있습니다.
안 정하시면 그냥 진행해도 됩니다.
```

> 🔑 **「받을 곳이 없다」고 하면 여기서 멈춥니다.**
> 사람이 와도 갈 데가 없으면 글을 아무리 잘 써도 소용이 없기 때문입니다.

## 2. 1~2단계 · 몇 편이 되나, 어떻게 펼치나

```
1단계 · 이 이야기에서 「서로 다른 결론」이 몇 개 나오나?

  결론 A  첫 화면은 설명하는 자리가 아니라 결정하는 자리다
  결론 B  내가 만든 것도 남이 보면 똑같이 넘긴다

둘입니다. 여러 편으로 갈 수 있습니다.

2단계 · 어떻게 펼칠까요. 네 가지 중에서 고릅니다.

  ① 채널 나누기    거의 항상 씁니다
  ② 다르게 보기     결론이 두 개 이상일 때
  ③ 결과 알리기 ⭐  1편에 숫자를 걸고, 며칠 뒤 결과를 올립니다
  ④ 자르기(연재)    팔로워가 있을 때만

① + ③ 을 고르겠습니다.

왜 — 지금 팔로워가 적으시니 ④는 위험합니다(2부를 볼 사람이 없습니다).
③은 "체크리스트를 몇 명이 받아 갔는지"를 며칠 뒤 올릴 수 있어서,
사람들이 결과를 보러 돌아옵니다.

다른 걸 원하시면 바꾸겠습니다.
```

## 3. 3~4단계 · 나오는 표 — **이게 결과물입니다**

```
| 편 | 언제  | 채널   | 각도                    | 종류         | 링크        |
|---|------|--------|------------------------|-------------|-------------|
| 1 | 9/10 | 스레드  | 내가 껐던 이야기 (시간순)  | 믿게 만드는 글 | 없음         |
| 2 | 9/11 | 인스타  | 결론 먼저 + 정리 장       | 믿게 만드는 글 | 프로필에      |
| 3 | 9/13 | 스레드  | "체크리스트 만들었다"      | 보내는 글     | 신청 폼 (짧게) |
| 4 | 9/16 | 스레드  | "몇 명이 받아 갔다"        | 보내는 글     | 신청 폼 (짧게) |
```

**왜 1·2편에는 링크가 없나**

```
🔴 글마다 링크를 붙이면 사람들이 그 계정을 광고로 봅니다.
특히 속마음을 쓴 글에 링크가 붙으면, 앞의 진심이 미끼처럼 보입니다.

그래서 글을 두 종류로 나눕니다.

  믿게 만드는 글   링크 없음   이 사람 말을 믿게 만든다
  보내는 글        링크 있음   실제로 신청 페이지로 데려간다

비율은 보내는 글 하나에 믿게 만드는 글 둘 이상.
1·2편이 믿게 만드는 글이고, 3편이 보내는 글입니다.
```

**채널마다 링크를 놓을 수 있는 자리가 다릅니다**

```
스레드   본문 마지막 칸 · 프로필 링크
인스타   🔴 캡션의 주소는 눌리지 않습니다. 프로필 링크만
블로그   본문 중간 · 글 끝 (맨 위는 안 됩니다 — 읽기 전에 파는 것처럼 보입니다)
```

## 4. 5단계 · 꼬리표 — 어디서 온 사람인지 알려면

```
같은 링크를 세 군데 던지면 세 군데를 구분할 수 없습니다.
그게 꼬리표를 붙이는 유일한 이유예요.

칸은 다섯인데 세 개만 채우면 됩니다.

  utm_source     어디에 뿌렸나      threads · instagram
  utm_medium     어떤 형태로        post · profile_link
  utm_campaign   어떤 건으로        0913_checklist

만든 링크

  3편 (스레드 본문)
  https://내폼주소?utm_source=threads&utm_medium=post&utm_campaign=0913_checklist

  2편 (인스타 프로필)
  https://내폼주소?utm_source=instagram&utm_medium=profile_link&utm_campaign=0913_checklist

🔴 이대로 던지지 마세요. 아무도 안 누릅니다. 짧게 줄여서 뿌립니다.
그리고 짧은 링크 서비스가 클릭 수를 세어줍니다 — 7단계가 여기에 달려 있습니다.

정한 말은 재료 폴더의 utm-terms.md 에 적어두겠습니다.
다음에도 같은 말을 써야 표가 안 엉킵니다.
```

> 🚪 **목적지가 「자리형」이면 이 단계를 통째로 건너뜁니다.**
> 슬랙 댓글로 받는 모집 같은 건 붙일 링크가 없으니까요.
> 대신 **「뭘 하면 되는지」 한 줄**을 넣습니다.
>
> ```
> ❌ "관심 있으면 연락 주세요"        → 뭘 하라는 건지 모릅니다
> ✅ "댓글에 「신청」 한 줄만 남겨주세요"
> ```

## 5. 6~7단계 · 언제 올리고, 뭘 세나

```
6단계 · 순서와 간격

  믿게 만드는 글이 먼저, 보내는 글이 나중입니다.
  같은 채널이면 최소 하루를 띄웁니다. 붙여 올리면 뒤 글이 앞 글을 덮습니다.
  같은 날 다른 채널은 괜찮습니다.

7단계 · 올린 뒤 뭘 세나

  | 채널    | 눌렀다 | 남겼다 | 남긴 비율 |
  |--------|-------|-------|---------|
  | 스레드   |       |       |         |
  | 인스타   |       |       |         |

🔴 못 채웠을 때가 더 중요합니다. 어디서 끊겼는지 셋 중 하나로 답이 나옵니다.

  아무도 안 눌렀다        → 채널·콘텐츠 문제
  눌렀는데 금방 나갔다     → 첫 화면 문제
  끝까지 갔는데 안 남겼다   → 폼·혜택 문제
```

## 6. 글은 누가 쓰나

**이 스킬은 배치만 합니다.** 문장은 안 씁니다.

```
글쓰기 스킬(sns-writing)이 있으시네요. 배정표를 넘기겠습니다.

  1편을 쓰시려면:  "1편 스레드 글 써줘"
  없으면:          편마다 뼈대만 내고 문장은 직접 쓰시면 됩니다
```

> 📖 **그다음이 궁금하시면** `../sns-writing/EXAMPLE.md` 를 보세요.
> **바로 이 1편을 쓰는 과정**이 거기 담겨 있습니다.

## 자주 막히는 곳 넷

| 증상 | 원인 | 어떻게 |
|---|---|---|
| **0단계에서 멈춘다** | 받을 곳이 아직 없음 | 🔵 **그게 맞습니다.** 폼부터 만드세요. 없이 만들면 온 사람이 갈 데가 없습니다 |
| **글을 안 써준다** | 이 스킬은 **배치만** 합니다 | `sns-writing` 을 같이 깔거나, 뼈대를 받아 직접 쓰시면 됩니다 |
| **꼬리표 단계가 안 나온다** | 목적지가 **자리형**이라 건너뛴 것 | 정상입니다. 붙일 링크가 없으니까요 |
| **표가 너무 많은 편으로 나온다** | 결론이 여러 개라고 판정됨 | *"두 편으로 줄여줘"* 하시면 됩니다. **억지로 늘리지 않는 게 원칙**입니다 |

| 5 | **없는 숫자를 만들지 않는다** | 4편의 *"몇 명이 받아 갔다"* 는 **실제로 센 다음에** 씁니다 |

## 온라인만이 아닙니다

전단·명함·배너에 **QR** 을 넣는 규칙도 들어 있습니다.

```
QR 크기 = 보는 거리 ÷ 10
  명함 (15~20cm)      1.5~2cm
  책상 위 전단 (50cm)   5cm
  벽 배너 (2m)         20cm

🔴 QR만 있으면 아무도 안 찍습니다. 세 줄이 붙어야 합니다.
  ① 무엇이 나오나   "3분이면 체크리스트 한 장"
  ② 왜 지금인가     "9월 13일까지"
  ③ 찍는 법 (선택)  "카메라로 비추세요"

🔴 인쇄 전에 반드시 실제로 찍어봅니다. 인쇄하고 나면 못 고칩니다.
```
