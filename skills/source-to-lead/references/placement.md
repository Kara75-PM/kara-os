# 어디에 링크·QR을 붙이나

3·4단계에서 읽는다. **채널마다 링크를 놓을 수 있는 자리가 다르다.**

---

## 먼저 · 편을 두 종류로 나눈다

| 종류 | 링크 | 역할 | 비율 |
|---|---|---|---|
| **믿게 만드는 글** | ❌ 없음 | 이 사람 말을 믿게 만든다 | **2 이상** |
| **보내는 글** | ✅ 있음 | 실제로 목적지로 데려간다 | **1** |

🔴 **글마다 링크를 붙이면 사람들이 그 계정을 광고 계정으로 본다.**
그리고 **감정선이 깊은 글에 링크가 붙으면 앞의 진심이 미끼처럼 보인다.**

---

## 「내 표시」 — **있으면 쓰고, 없으면 대신 쓴다**

**여러 장을 이어 만들 때 「같은 사람 것」으로 보이게 하는 표시**다.
한 장 한 장 예쁜 것보다, **여러 장이 같은 계정 것으로 보이는 게** 훨씬 중요하다.

### 🟢 캐릭터·로고가 있으면

| | |
|---|---|
| **넣는 곳** | **표지 1장 + 마지막 1장, 두 곳만** |
| 🔴 **안 넣는 곳** | **정리 장** — 캡처해 가는 장이라 정보만 있어야 한다 |
| 중간 장 | 안 넣는다. 매 장 넣으면 질리고, 글자가 밀린다 |
| **크기** | 표지 그림 높이의 **40~45%** · 마지막 **30~35%** (마지막이 더 작게) |
| **자리** | 표지는 **오른쪽 아래** · 마지막은 **가운데 아래.** 바닥에 붙인다 |

**🔑 시선 방향이 중요하다**

| 어디에 두나 | 어느 쪽을 보게 |
|---|---|
| 오른쪽에 두면 | **왼쪽(글자 쪽)을 보게** — 시선이 글자를 가리킨다 |
| 왼쪽에 두면 | 오른쪽(글자 쪽)을 보게 |
| **마지막 장** | **정면.** 읽는 사람을 마주 보며 닫는다 |

> ⚠️ **투명 배경 그림은 여백이 들어 있는 경우가 많다.**
> 눈대중으로 크기를 잡으면 실제보다 작게 보인다. **여백을 먼저 잘라내고** 크기를 잡는다.

### ⚪ 캐릭터·로고가 없으면 — 대신 쓸 것 넷

**없다고 건너뛰지 않는다.** 표식이 없으면 시리즈로 안 보인다.

| 대신 쓸 것 | 어떻게 |
|---|---|
| **색 하나 고정** | 강조색을 하나만 정하고 모든 장에서 그 색만 쓴다 |
| **도형 하나** | 제목 위에 짧은 색 막대 하나 — 모든 장 같은 자리에 |
| **반복되는 문장** | 마지막 장에 늘 같은 한 줄 |
| **손글씨 서명** | 마지막 장 아래에 이름 한 번 |

**하나만 고른다.** 여러 개를 쓰면 그게 곧 표식이 없는 것이다.

## 온라인 채널

### 스레드 (Threads)

| 자리 | 되나 | 어떻게 |
|---|---|---|
| **본문 안 링크** | ✅ 눌린다 | **마지막 칸**에만. 중간에 넣으면 **거기서 나가버린다** |
| **프로필 링크** | ✅ | 믿게 만드는 글은 여기로만 보낸다 |

**권하는 방식**

```
믿게 만드는 글   링크 없음 → 궁금한 사람이 프로필을 누른다
보내는 글 마지막 칸에 한 줄 + 링크
```

> 링크를 넣을 땐 **왜 눌러야 하는지**를 앞 칸에서 이미 말해두어야 한다.
> 갑자기 나온 링크는 안 눌린다.

### 인스타그램

🔴 **인스타는 본문(캡션)에 넣은 주소가 눌리지 않는다.** 글자로만 보인다.

| 자리 | 되나 | 어떻게 |
|---|---|---|
| 캡션 안 주소 | ❌ **안 눌린다** | 쓰지 않는다. 쓸 거면 *"프로필 링크로"* 라고 안내 |
| **프로필 링크** | ✅ | **인스타에서 늘 열려 있는 유일한 통로** |
| **스토리 링크 스티커** | ✅ | 24시간만 남는다 |
| **캐러셀 마지막 장** | — | 링크가 아니라 **「프로필 링크로 오세요」 안내 장** |

**권하는 방식**

```
캐러셀 마지막 장   "프로필 링크에 있습니다" 한 줄
캡션 마지막 줄     같은 안내
프로필 링크        목적지 주소 (UTM 붙인 것)
```

> **프로필 링크 자리는 좁다.** 지금 밀고 있는 목적지 **하나만** 거는 게 낫다.
> 여러 개를 걸면 사람들이 뭘 눌러야 할지 몰라서 아무것도 안 누른다.
> 꼭 여러 개가 필요하면 링크 모음 페이지를 하나 두고 그걸 건다.

### 블로그

| 자리 | 어떻게 |
|---|---|
| **본문 중간** | 관련 있는 문단 바로 아래. 자연스럽게 |
| **글 끝** | 한 번 더 |
| 글 맨 위 | ❌ **쓰지 않는다.** 읽기 전에 파는 것처럼 보인다 |

블로그는 **검색으로 들어오는 곳**이라, 링크보다 **답을 먼저** 줘야 한다.

## 오프라인 — 전단 · 명함 · 배너 · 포스터

**손에 남는 것에는 주소를 못 적는다. QR로 보낸다.**

### QR을 무엇으로 만드나

| 방법 | 어떻게 |
|---|---|
| **에이전트가 만든다** | 파이썬 `qrcode` 라이브러리 (`pip install "qrcode[pil]"`) 로 PNG를 뽑는다 |
| 명령줄 | `qrencode` (맥 `brew install qrencode`) |
| 온라인 생성기 | 검색해서 쓰되, **주소가 남는 곳**이라 민감한 링크는 피한다 |

🔑 **QR에는 「짧은 링크」를 담는다.** 긴 UTM 주소를 그대로 넣으면 무늬가 촘촘해져 잘 안 찍힌다.

### QR 크기 — **거리 ÷ 10**

| 보는 거리 | 최소 한 변 |
|---|---|
| 손에 들고 (30cm) | **3cm** |
| 책상 위 전단 (50cm) | **5cm** |
| 벽 배너 (2m) | **20cm** |
| 명함 (15~20cm) | **1.5~2cm** |

> 작게 넣으면 안 찍힌다. **작게 넣을 바에는 빼는 게 낫다.**

### QR 옆에 반드시 있어야 할 것

🔴 **QR만 있으면 아무도 안 찍는다.** 세 줄이 붙어야 한다.

```
① 무엇이 나오나    "3분이면 카드 한 장"
② 왜 지금인가      "9월 13일까지"
③ 찍는 법 (선택)   "카메라로 비추세요"
```

### 배치 규칙

| 규칙 | 왜 |
|---|---|
| **QR 둘레에 흰 여백** (QR 한 칸 크기 이상) | 여백이 없으면 **카메라가 못 읽는다** |
| **어두운 배경에 흰 QR을 쓰지 않는다** | **색을 뒤집은 QR**은 못 읽는 카메라가 있다 |
| **접히는 자리·모서리를 피한다** | 전단이 접히면 그 부분이 깨진다 |
| **한 장에 QR 하나** | 두 개면 어느 걸 찍을지 고민하다 안 찍는다 |
| **인쇄 전에 실제로 찍어본다** | 🔴 **인쇄하고 나면 못 고친다** |

### 오프라인 카피 — 한 문장 규칙

**전단·배너는 지나가면서 본다. 한 문장이면 충분하고, 두 문장이면 안 읽는다.**

```
큰 글자 (한 문장)     지나가다 멈추게 하는 것
작은 글자 (한 줄)     무엇인지
QR + 세 줄            어디로 가는지
```

## 채널별 정리표

| 채널 | 링크 놓을 자리 | UTM `medium` |
|---|---|---|
| 스레드 | 마지막 칸 · 프로필 | `post` · `profile_link` |
| 인스타 | **프로필 링크만** · 스토리 스티커 | `profile_link` · `story` |
| 블로그 | 본문 중간 · 글 끝 | `post` |
| 오픈채팅방 | 메시지 안 | `dm` |
| 메일 | 본문 · 서명 | `body` · `signature` |
| **전단·명함·배너** | **QR** | `qr` |

## ⚠️ 확인이 필요한 것

플랫폼 규칙은 **바뀝니다.** 아래는 이 문서를 쓴 시점 기준이라,
**중요한 발행 전에는 실제로 한 번 눌러보고 확인**하세요.

- 인스타 캡션 링크가 안 눌리는 것
- 스토리 링크 스티커를 쓸 수 있는 조건
- 각 채널의 링크 개수 제한
