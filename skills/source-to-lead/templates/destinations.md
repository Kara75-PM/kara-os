# 목적지 목록

> **사람을 「어디로」 보낼지**의 목록입니다. 0단계에서 이 파일을 봅니다.
> 목적지가 없으면 콘텐츠를 만들어도 온 사람이 갈 데가 없습니다.

## 두 종류를 먼저 가릅니다

| | 🔗 링크형 | 🚪 자리형 |
|---|---|---|
| 주소가 | **있다** | **없다** |
| 예 | 신청 폼 · 랜딩 페이지 · 오픈채팅 초대 링크 | 슬랙 댓글 · DM · 오프라인 모임 |
| UTM 꼬리표 | 만든다 | **안 만든다** |
