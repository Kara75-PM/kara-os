# material-harvest — 내 대화에서 글감 캐기

> 🧩 카라 OS · 콘텐츠

**어제 나눈 클로드 대화 안에서 SNS에 쓸 얘기를 건져 올려 주는 도구입니다.**
쓸 거리가 없는 게 아니라, 그때 적어두지 않아서 잊은 것뿐입니다.

---

## 🔴 먼저 확인 — 클로드 코드에서만 캘 수 있습니다

| 이렇게 쓰고 계시면 | 캘 수 있나 |
|---|---|
| **클로드 코드** (터미널 · 데스크톱 앱의 Code 탭) | ✅ 됩니다 — 대화가 **내 컴퓨터에 파일로** 쌓여 있습니다 |
| **채팅** (claude.ai · 앱의 일반 채팅) | ❌ 안 됩니다 — 대화가 내 컴퓨터에 없어서 **읽을 게 없습니다** |

채팅에 스레드를 붙여 넣어 소재를 뽑는 것도 좋은 방법입니다. 이 도구는 **그 붙여 넣기를 없앤 것**입니다.
이미 컴퓨터에 쌓인 대화를 읽으니, 옮겨 적을 필요가 없습니다.

---

## 어떻게 쓰나

클로드에게 이렇게 말하면 됩니다.

```
소재 좀 캐줘
```
```
오늘 글감 있어?
```
```
다른 창에서 소재 긁어와줘
```

그러면 이 순서로 갑니다.

| 단계 | 무엇을 | 클로드가 |
|---|---|---|
| **0** | 어디서 캘지 정합니다 | 🔴 **먼저 묻습니다.** 폴더를 고르고, 그 안의 **창 제목 목록**에서 고르게 합니다. 고르기 전엔 대화를 열지 않습니다 |
| **1** | 읽을 수 있게 줄입니다 | 내가 한 말만 뽑습니다. **176MB 대화가 246KB 가 됩니다** |
| **2** | 기준에 걸린 것만 뽑습니다 | 다섯 가지 기준으로 봅니다 (아래) |
| **3** | 번호를 붙여 보여주고 **멈춥니다** | *"16번, 18번만 넣어"* 라고 하면 됩니다 |
| **4** | 고른 것만 파일에 쌓습니다 | **줄을 더하기만 합니다.** 넣은 뒤 원래 줄이 다 남았는지 확인해 보여줍니다 |
| **5** | 어디까지 캤는지 적어둡니다 | 다음에 **같은 걸 두 번 캐지 않게** |

> **자동으로 돌지 않습니다.** 말할 때만 돕니다.
> 자동으로 쌓으면 소재 파일이 쓰레기통이 됩니다.

## 무엇을 소재로 보나 — 기준 다섯 가지

| # | 기준 | 이런 게 걸립니다 |
|---|---|---|
| 1 | **숫자가 남았나** | *"3번 넣었는데 3번 다 실패"* |
| 2 | **예상과 달랐나** | *"짧아질 거라던 내 예상이 틀렸다"* |
| 3 | **아직 안 끝났나** | *"아직 아무도 안 썼다"* |
| 4 | **겪은 사람만 아는가** | *"항목 이름이 「화면 기록」이 아니었다"* |
| 5 | **누가 뭐라고 말했나** | *"00시 33분에 사람이 쓴 답장이 왔다"* |

**두 개 이상 걸린 것을 위로 올립니다.** 하나만 걸린 것은 「약하다」고 적어 아래에 둡니다.

> **기준은 고칠 수 있습니다.** `SKILL.md` 의 표에 한 줄을 더하거나 지우면 됩니다.
> 사람마다 쓰는 소재가 다르니, 받으신 뒤 본인 것으로 바꾸셔도 됩니다.

## 다른 소재 도구와 뭐가 다른가

소재를 찾아 주는 도구는 이미 여러 개 있습니다. 대개 **바깥**을 봅니다.

| | 재료를 어디서 가져오나 |
|---|---|
| 바깥을 보는 도구 | 남의 글 · 레퍼런스 사이트 · 인터뷰 답변 → **따로 적어 넣어야 합니다** |
| **이 도구** | **이미 쌓인 내 대화** → **따로 적을 필요가 없습니다** |

**차이는 그 하나입니다.** 소재 모으기가 실패하는 이유는 대개 좋은 일이 없어서가 아니라, **그때 적어두지 않아서**입니다. 대화는 이미 적혀 있습니다.

## 🔴 내 대화를 읽는 도구입니다 — 그래서 이렇게 막아뒀습니다

| | |
|---|---|
| **묻기 전에 읽지 않습니다** | 어느 폴더의 기록을 볼지 **목록을 보여주고 고르게 합니다** |
| **무엇을 읽었는지 밝힙니다** | 폴더 이름과 기간을 결과에 적습니다 |
| **답변은 안 읽습니다** | 내가 한 말만 봅니다. 그래서 용량이 1% 아래로 줄어듭니다 |
| **AI와 말이 어긋난 일은 소재로 안 봅니다** | 남이 읽어도 가져갈 게 없어서입니다. 남도 겪을 교훈이 있을 때만 올립니다 |
| **비밀은 소재로 만들지 않습니다** | 비밀번호·열쇠값·고객 이름이 보이면 **본 사실만 알리고 넘어갑니다** |
| **남의 말은 이름을 뺍니다** | 채팅방·댓글에서 본 남의 문장은 요지만. 그대로 쓰려면 허락이 필요합니다 |

일 관계로 갈라둔 폴더(회사 과제·남과 같이 쓰는 저장소)는 **목록에는 올리되 고르기 전엔 열지 않습니다.**

## 설치

### 맥 · 리눅스 — 어느 폴더에서 일하든 쓸 수 있게

```bash
D=$(mktemp -d) && git clone --depth 1 https://github.com/Kara75-PM/kara-os.git "$D" && bash "$D/install.sh"
```

### 윈도우 (PowerShell)

```powershell
$d = Join-Path $env:TEMP ("kara-os-" + [guid]::NewGuid()); git clone --depth 1 https://github.com/Kara75-PM/kara-os.git $d; powershell -ExecutionPolicy Bypass -File "$d\install.ps1"
```

> 위 한 줄은 `kara-os` 를 통째로 받은 뒤 **무엇을 깔지 물어봅니다.**

### 확인

```bash
find ~/.claude/skills/material-harvest -name '*.md'
```

**문서 3개**(SKILL · README · EXAMPLE)가 나오면 성공입니다.

### 🔴 설치했는데 안 불릴 때

**클로드 코드를 껐다 켜 보세요.**

처음 설치하는 분은 `.claude/skills` 폴더가 **이번에 처음 생깁니다.**
클로드 코드는 켜질 때 그 폴더를 찾는데, 켜질 당시엔 없었으니 못 봅니다.
**껐다 켜면 그때 찾습니다.** 고장이 아닙니다.

## 캔 소재는 어디에 쌓이나

**「재료 폴더」** 라는 곳에 쌓입니다. 스킬 폴더 **바깥**입니다.

```
kara-os-private/
  └─ material-stash.md   ← 캔 소재가 여기 쌓입니다
```

🔒 **스킬 폴더 바깥이라 인터넷에 안 올라갑니다.** 내 컴퓨터에만 있습니다.

> **왜 굳이 폴더를 나눴나요?**
> 스킬은 깃허브에 **공개로** 올라가 누구나 받아 씁니다. 캔 소재는 **내가 겪은 일**입니다.
> 한 폴더에 섞여 있으면, 스킬을 고쳐 올릴 때 내 이야기까지 같이 올라갈 수 있습니다.
> 그래서 **「남과 나누는 것」과 「나만 갖는 것」을 처음부터 다른 폴더에** 둡니다.

**없으면 클로드가 만들어 줍니다.** 이렇게 말하면 됩니다.

```
재료 폴더 만들어줘
```

깃으로 관리하는 폴더면 **`.gitignore` 에 넣을지도 물어봅니다.**
같이 쓰는 저장소면 그 사실을 먼저 알려주고 묻습니다.

> **`sns-writing` 을 이미 쓰고 계시면 같은 폴더를 씁니다.** 새로 안 만듭니다.

## 캔 뒤에는

이 도구는 **글을 쓰지 않습니다.** 글감만 골라 줍니다.

| 다음에 | 이렇게 |
|---|---|
| 글을 쓰려면 | `sns-writing` 에 넘깁니다 — *"이 소재로 스레드 글 써줘"* |
| 여러 편으로 펼치려면 | `source-to-lead` 에 넘깁니다 |
| 둘 다 없으면 | 소재 표만 남습니다. **그것으로도 쓸모가 있습니다** |

## 이럴 땐 쓰지 마세요

- **글을 다듬는 일** — 이 도구는 글감만 찾습니다
- **남의 대화에서 캐는 일** — 내 기록만 봅니다
- **채팅(claude.ai)으로 나눈 대화에서 캐는 일** — 내 컴퓨터에 없어서 못 봅니다 (맨 위 「먼저 확인」)
- **자동으로 매일 쌓기** — 일부러 안 되게 했습니다. 쓰레기가 쌓입니다
