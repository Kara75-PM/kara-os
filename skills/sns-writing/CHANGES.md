**원본:** 노슈니(오수인)님의 `threads-writing` (스폰지클럽 3기 스킬러스 유닛 공유)
**갈라진 날:** 2026-09-03

---

## 왜 바꿨나 — 한 문장

원본을 받아서 써보니 **만든 사람의 재료가 파일 안에 박혀 있었다.**
그래서 **「만드는 방식」과 「쓰는 사람의 재료」를 분리**했다.

---

## 바꾼 것 5가지

### 1. 재료를 스킬 밖으로 뺐다 ⭐ 가장 큰 변화

| | 원본 | 이 스킬 |
|---|---|---|
| 글쓴이 정보 | 파일 안에 있음 | **폴더 밖 `sns-writing-private/`** |
| 소재 | 파일 안에 예시로 있음 | **폴더 밖 `material-stash.md`** |
| 어투 | 만든 사람 문체가 배어 있음 | **폴더 밖 `my-voice.md`** — 쓸수록 쌓임 |

**왜:** 등록하면 공개 저장소에 올라간다. 개인 정보를 애초에 안 넣으면 지울 일도 없다.
그리고 **남이 받아도 자기 재료로 바로 돈다.**

`SKILL.md` 맨 앞에 재료 폴더를 찾는 순서를 넣었다. **없으면 그냥 물어보며 진행한다 — 안 깨진다.**

### 2. 채널을 고르는 0단계를 새로 넣었다

원본은 스레드 전용이었다. 스레드 규칙(7~12칸·볼드 금지)이 본체에 섞여 있었다.

**본체에서 떼어내 채널 파일로 분리했다.**

```
references/channel-threads.md      ← 본체에서 떼어낸 스레드 규칙
references/channel-instagram.md    ← 원본 cardnews.md 를 채널 파일로 승격
```

**왜:** 채널을 추가할 때 `channel-○○.md` 한 장만 더 쓰면 된다.
훅·소재·재료는 그대로 재사용된다.

### 3. 채널을 가리지 않는 원칙을 본체로 올렸다

원본에서 스레드 얘기와 섞여 있던 것 중 **어느 채널에서든 통하는 5가지**를 본체로 뽑았다.

1. 첫 자리가 전부다 · 2. 자극은 세게, 상처는 없게 · 3. 글의 두 유형 ·
4. 문장 기술 · 5. 마무리와 CTA

*"1번 칸"* 이라는 스레드 전용 표현을 **"첫 자리(스레드 1번 칸 · 인스타 표지)"** 로 바꿨다.

### 4. 훅 예시에서 실존 인물·브랜드를 뺐다

원본 훅 예시 8개 중 **3개가 실존 인물·브랜드**를 그대로 쓰고 있었다.

| 유형 | 원본 | 바꾼 것 |
|---|---|---|
| 손해를 먼저 말하기 | 특정 브랜드·유통 채널 이름 | 이름 없이 구조만 |
| 통념 뒤집기 | 특정 가수·곡 이름 | 이름 없이 구조만 |
| 반박 불가능한 관찰 | 특정 가수·곡 이름 | 이름 없이 구조만 |

**왜:** ① 예시가 「형태」를 보여주면 되지 특정 인물이 필요하지 않다.
② 실존 인물을 예시로 박아두면 그 각도로만 생각하게 된다.

### 5. 소재 파일에 「재료 폴더가 먼저」라는 순서를 박았다

원본 `topic-mining.md` 는 카테고리만 있어서, 매번 사용자에게 질문해 캐내는 구조였다.

**앞에 순서를 넣었다.**
1. 재료 폴더의 `material-stash.md` 를 **먼저** 읽는다
2. 거기서 카테고리에 맞춰 후보를 뽑는다
3. 비어 있을 때만 질문으로 캐낸다
