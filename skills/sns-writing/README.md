# sns-writing — 내 이야기로 SNS 글 쓰기

> 🧩 카라 OS · 콘텐츠

**스레드와 인스타그램에 올릴 글을 클로드가 대신 써 주는 도구입니다.**
내 이야기를 한 번만 적어두면, 그다음부터 내 말투로 씁니다.

---

## 어떻게 쓰나

클로드에게 이렇게 말하면 됩니다.

```
스레드 글 써줘
```
```
이 글 인스타로 옮겨줘
```
```
이 글이 왜 잘된 건지 봐줘
```

그러면 이 순서로 갑니다.

| 단계 | 무엇을 | 클로드가 |
|---|---|---|
| **0** | 어디에 올릴지 정합니다 | 스레드인지 인스타인지 묻습니다 |
| **1** | 무슨 이야기인지 정합니다 | *"이 글의 결론이 뭔가요"* 를 한 줄로 맞춥니다 |
| **2** | 사실을 확인합니다 | 사람 이름·숫자·날짜가 나오면 **검색해서 맞춰봅니다** |
| **3** | **첫 문장 후보 3개**를 줍니다 | 서로 다른 각도로. 고르시면 됩니다 |
| **4** | 전체를 씁니다 | **그대로 복사해 올릴 수 있는 모양**으로 |
| **5** | 올린 뒤 배웁니다 | 고치신 걸 보고 **내 말투를 기록해 둡니다** |

> **첫 문장(훅)** — 스레드의 첫 칸, 인스타의 첫 장을 말합니다.
> **여기서 볼지 말지가 갈립니다.** 그래서 후보를 세 개 드립니다.

---

## 다른 글쓰기 도구와 뭐가 다른가

남이 만든 글쓰기 도구에는 **그 사람 이야기가 안에 박혀 있습니다.**
그 사람 회사, 그 사람이 하던 일, 그 사람 말투. 그래서 쓸 때마다 지워야 합니다.

**이 도구는 그 둘을 갈라놓았습니다.**

| | 어디에 | 남이 볼 수 있나 |
|---|---|---|
| **쓰는 방법** — 첫 문장 잡는 법, 글자 수, 칸 나누는 법 | 이 폴더 안 | ✅ 봐도 됩니다 |
| **내 이야기** — 내가 누구인지, 겪은 일, 내 말투 | **이 폴더 바깥**의 「재료 폴더」 | ❌ 내 컴퓨터에만 |

## 설치

### 맥 · 리눅스 — 어느 폴더에서 일하든 쓸 수 있게

```bash
D=$(mktemp -d) && git clone --depth 1 https://github.com/Kara75-PM/kara-os.git "$D" && bash "$D/install.sh"
```

### 윈도우 (PowerShell)

```powershell
$d = Join-Path $env:TEMP ("kara-os-" + [guid]::NewGuid()); git clone --depth 1 https://github.com/Kara75-PM/kara-os.git $d; powershell -ExecutionPolicy Bypass -File "$d\install.ps1"
```

### 이것만 깔고 싶으면

```bash
bash "$D/install.sh" sns-writing
```

아무것도 안 붙이면 목록을 보여주고 번호로 고르게 합니다.
지금 프로젝트에만 넣으려면 `--local` (윈도우는 `-Local`) 을 붙이세요.

### 확인

```bash
find ~/.claude/skills/sns-writing -name '*.md'
```

**문서 10개**가 나오면 성공입니다.

> 위 한 줄은 `kara-os` 를 통째로 받은 뒤 **무엇을 깔지 물어봅니다.**

### 🔴 설치했는데 안 불릴 때

**클로드 코드를 껐다 켜 보세요.**

처음 설치하는 분은 `.claude/skills` 폴더가 **이번에 처음 생깁니다.**
클로드 코드는 켜질 때 그 폴더를 찾는데, 켜질 당시엔 없었으니 못 봅니다.
**껐다 켜면 그때 찾습니다.** 고장이 아닙니다.

## 「재료 폴더」 만들기 — 안 만드셔도 됩니다

없으면 클로드가 그냥 물어보면서 씁니다. **안 깨집니다.**
다만 만들어두면 **매번 자기 설명을 다시 안 해도 됩니다.**

### 만드는 법 — 클로드에게 시키세요

```
재료 폴더 만들어줘
```

> 🔑 **직접 폴더를 만들지 마세요.** 위치가 조금만 달라도 도구가 못 찾습니다.
> 클로드는 지금 어느 폴더에서 일하는지 알고 있어서 **틀릴 수가 없습니다.**

그러면 클로드가 이렇게 합니다.

```
① 폴더를 만듭니다                    kara-os-private/
② 예시가 채워진 파일 3개를 넣습니다     지우고 내 걸로 바꾸면 됩니다
③ 깃(git) 폴더인지 확인하고 물어봅니다
```

### 🔴 ③이 중요합니다

작업하는 폴더가 **깃으로 관리되는 폴더**면, 내 이야기가 **인터넷에 딸려 올라갈 수 있습니다.**
그래서 클로드가 이렇게 물어봅니다.

```
이 폴더는 깃으로 관리되고 있습니다.
지금 작업 폴더의 .gitignore 에 한 줄을 더할까요? (없으면 새로 만듭니다)

  *-private/
```

> **저장소 뿌리가 아니라 「지금 작업 폴더」에 넣습니다.** 뿌리 파일은 같이 쓰는 사람들 것이라서요.
> 이미 같은 줄이 있으면 아무것도 안 합니다. 넣은 뒤 **정말 막혔는지 확인해서 보여줍니다.**

**「네」라고 하시면 됩니다.** 그 한 줄이 막아줍니다.

> 깃이 뭔지 모르시면 신경 안 쓰셔도 됩니다. 안 쓰시면 이 질문 자체가 안 나옵니다.

### 만들어지는 파일 3개

| 파일 | 뭘 적나 |
|---|---|
| `who-i-am.md` | 내가 누구인지 한두 줄. **말투와 시선의 기준**이 됩니다 |
| `material-stash.md` | 겪은 일을 **한 줄씩.** 다듬지 마세요 |
| `my-voice.md` | 내 말투. **처음엔 비워두세요** — 글을 쓸수록 클로드가 채웁니다 |

## 안에 뭐가 들어 있나

```
sns-writing/
  SKILL.md          클로드가 읽는 설명서 (사람은 안 읽어도 됩니다)
  README.md         이 파일
  CHANGES.md        원본에서 무엇을 바꿨는지
  templates/        예시가 채워진 견본 3개
  references/       더 자세한 참고 자료 4개
```

| 참고 자료 | 무엇이 들어 있나 |
|---|---|
| `channel-threads.md` | 스레드에 맞는 형식 — 칸 수, 한 칸 길이, 첫 칸 잡는 법 |
| `channel-instagram.md` | 인스타 여러 장짜리 게시물 — 장수 배분, 카드 만드는 HTML |
| `hooks.md` | 첫 문장 8가지 유형 + **실제 예시 문장** |
| `topic-mining.md` | 쓸 이야기가 없을 때 캐내는 방법 |

> **`references/` 가 없어도 도구는 돕니다.** `SKILL.md` 안에 핵심 요약이 들어 있습니다.
> 다만 예시 문장이 빠지므로 **통째로 받으시는 게 좋습니다.**
