> 검토일: 2026-10-08 · 기준 커밋: `ba4b5c0`
> **`skills/` 안의 파일은 하나도 고치지 않았다.** 이 문서는 읽고 적기만 한 결과다.

## 먼저 짚을 것 두 가지

1. **`skills/material-harvest/references/` 는 없다.** 이 스킬은 `SKILL.md · README.md · EXAMPLE.md` 세 장뿐이다 (루트 `README.md:334` 도 그렇게 말한다).
   그래서 「references」 칸에는 **이 스킬이 기대고 있는 sns-writing 쪽 자료**를 대신 놓고 비교했다.
   - `skills/sns-writing/references/topic-mining.md` — 「뭘 쓰지」·「글감」 에 반응하는 다른 스킬의 소재 문서
   - `skills/sns-writing/templates/material-stash.md` · `who-i-am.md` — material-harvest 가 읽고 쓰는 재료 폴더 파일의 견본 (`source-to-lead/templates/` 의 같은 이름 파일과 글자까지 같음)
   - `skills/sns-writing/SKILL.md` — 같은 재료 폴더를 찾는 규칙
2. **파일 이름은 요청대로 `sns-writing.md` 로 두었다.** 내용은 material-harvest 검토다. 이름을 바꿀지는 정해 주면 된다.

줄 번호는 `파일:줄` 로 적었다. `R` = material-harvest/README.md, `S` = material-harvest/SKILL.md, `E` = material-harvest/EXAMPLE.md, `sw-S` = sns-writing/SKILL.md, `tm` = sns-writing/references/topic-mining.md, `t-stash` · `t-who` = sns-writing/templates/ 의 견본.

무게: **높음** = 스킬이 다르게 움직이거나 규칙을 어길 수 있음 · **중간** = 사람이 잘못 알아듣기 쉬움 · **낮음** = 표기·예시 차이

## 2) 부르는 말 · 부르면 안 되는 말

「맞는 반응」은 **SKILL.md 규칙**을 기준으로 적었다. 문서끼리 갈리는 곳은 위 표 번호를 달았고, 문서에 절차가 없는 곳은 **「문서에 없음 — 권하는 반응」** 으로 표시했다.

### 이 스킬을 불러야 하는 말 10개

| # | 사용자가 하는 말 | 맞는 반응 |
|---|---|---|
| 1 | 소재 좀 캐줘 | 재료 폴더를 순서대로 찾고(`S:26-33`), 보관소 맨 위 다섯 줄로 시험용인지 보고, `who-i-am.md` 를 읽는다. **대화 파일은 하나도 열지 않고** 폴더 목록(이름·파일 수·크기·수정 날짜)만 보여 주고 멈춘다. 🔒 폴더는 목록에만 |
| 2 | 어제 클로드랑 한 얘기 중에 스레드에 쓸 만한 거 있었어? | 1번과 같이 시작한다. 「어제」는 기간 후보로 받아 두되, **창을 고르기 전엔 읽지 않는다**. 두 번째 질문에서 창을 묻고 기간 「어제부터」가 맞는지 확인한다. 글을 쓰지는 않는다 |
| 3 | 다른 창에서 소재 긁어와줘 | 첫 질문(폴더) → 고른 폴더만 열어 **창 제목 목록**(제목·마지막으로 말한 시각·최근 3일 말 수)을 보여 준다. 창 목록엔 대화 글자를 내지 않는다(`S:127`). 「다른 창」이 어느 창인지 **짐작하지 않고** 고르게 한다 |
| 4 | 오늘은 여기서 마감하자. 오늘 뭐 건졌나? | 설명의 「세션 마감」 경우(`S:3`). 1번 흐름으로 가되, 기간은 「오늘」 또는 「지난번 캔 곳 이후」를 첫 선택지로 둔다(`S:153`). **자동으로 넣지 않는다** — 후보 표를 보여 주고 멈춘다. (마감 때 스킬이 먼저 묻는지는 표 5번 참고) |
| 5 | 글감이 없어 | 설명상 이 스킬이 맡는다. 다만 sns-writing 도 「글감 없을까」를 맡는다(표 11번). **권하는 반응:** 0단계 첫 질문은 아무것도 열지 않으니 그대로 시작하되, 한 줄 덧붙인다 — *"대화 기록에서 캐 볼까요? 바깥 재료로 후보를 받고 싶으면 sns-writing 으로 넘기겠습니다."* |
| 6 | work-app 폴더에서 최근 3일치 캐줘 | 폴더·기간이 정해졌으니 첫 질문을 건너뛰고 **work-app 만** 열어 창 목록을 보여 주고 **창만 다시 묻는다**(빠진 것만, `S:169-170`). 고른 뒤 읽기 전에 **양부터 센다**(창 5개·7일·150KB 한도, `S:179-186`) |
| 7 | 지난 2주 대화 전부 훑어서 소재 뽑아줘 | 「전부」는 되묻는다(`S:171`). 폴더·창을 고른 뒤에도 기간 14일이 **7일 한도**를 넘으니 **읽기 전에 멈추고** 「기간 줄여 / 창 줄여 / 그래도 해」를 보여 준다. **「그래도 해」라고 분명히 답했을 때만** 읽는다(`S:198`) |
| 8 | 이거 소재보관소에 넣어줘 — 오늘 리허설 세 번 했는데 세 번 다 7분 넘김 | 설명엔 있으나 절차가 없다(표 21번). **문서에 없음 — 권하는 반응:** 대화 기록은 **열지 않는다**(읽을 것이 없다). 사용자 문장을 **다듬지 않고** 보관소 모양대로(날짜 + 한 줄, 또는 다음 번호) 넣을 줄을 보여 주고, 사본 → 넣기 → 줄 대조 → 전체 경로를 보인다(`S:433-460`). 「마지막으로 캔 곳」 표시는 **건드리지 않는다**(읽은 말이 없으므로, `S:482`) |
| 9 | 소재 보관소 보여줘 | 설명엔 있으나 절차가 없다(표 21번). **문서에 없음 — 권하는 반응:** 재료 폴더를 찾고 **찾은 보관소의 전체 경로**와 내용을 보여 준다. 대화 기록은 열지 않고, 파일에 **아무것도 쓰지 않는다**. 끝에 「캐 볼까요?」 한 번만. 재료 폴더가 없으면 「만들어 둘까요?」 한 번만(`S:75`) |
| 10 | 이번엔 시험이야. 캐 보기만 하고 넣지는 마 | 🧪 모드(`S:387-395`). 흐름은 똑같이 0단계부터 묻되 보관소엔 **한 글자도 안 쓰고** 표시도 안 적는다. 캐기 **전후 sha256** 을 떠서 같음을 보여 주고, 「지금 할 수 있는 것」 대신 *"시험이라 무엇을 고르셔도 넣지 않습니다…"* 한 줄로 닫는다 |

## 한 것 · 못 한 것 · 확인 안 한 것

### 한 것

- `skills/material-harvest/` 의 README.md · SKILL.md · EXAMPLE.md 를 처음부터 끝까지 읽었다
- references 가 없어서, 이 스킬이 기대는 `sns-writing/references/topic-mining.md`, `sns-writing/templates/` 세 파일, `sns-writing/SKILL.md` 의 재료 폴더 부분, `source-to-lead/SKILL.md` 설명, 루트 `README.md` 의 material-harvest 부분, `install.sh` 의 안내 문구를 읽고 대조했다
- `sns-writing/templates/` 와 `source-to-lead/templates/` 의 `material-stash.md` · `who-i-am.md` 가 글자까지 같은지 `diff` 로 확인했다 (같음)
- EXAMPLE 의 숫자 몇 개를 손으로 맞춰 봤다 — 「원래 12줄」, 「4줄이라 5번부터」, 「보관소 2·3번째 줄과 비슷」, 표시 시각 `23:05:40` · `23:08:12` 는 모두 예제 안에서 맞았다
- 차이 26건을 표로, 부르는 말 10개 · 부르면 안 되는 말 5개를 표로 정리했다
- `skills/` 안의 파일은 고치지 않았다
- 열린 PR 을 봤다 — Kara75-PM/kara-os#4 (source-to-lead 검토)와 #5 (sns-writing 검토)도 **같은 경로 `docs/review/sns-writing.md`** 를 만든다. 하나가 합쳐지면 나머지는 충돌한다. 이름은 요청대로 두었다

### 못 한 것

- **`skills/material-harvest/references/` 는 없어서 그 자체와는 비교하지 못했다.** sns-writing 쪽 자료로 대신했다
- **스킬을 실제로 불러 보지 못했다.** 부르는 말 15개의 「맞는 반응」은 문서를 읽고 적은 것이고, 클로드 코드에서 그 말을 쳐서 정말 이 스킬이 불리는지, 두 스킬이 겹치는 말(표 11번)에 어느 쪽이 불리는지는 돌려 보지 않았다
- 문서 사이 차이를 **어느 쪽으로 맞춰야 하는지는 정하지 않았다.** 고치는 건 요청 범위 밖이라 「생기는 일」까지만 적었다

### 확인 안 한 것

- `sns-writing/references/` 의 나머지 세 파일(`hooks.md` · `channel-threads.md` · `channel-instagram.md`)과 sns-writing · source-to-lead 의 EXAMPLE·README 전체는 material-harvest 와 직접 닿는 부분만 찾아 봤고, 처음부터 끝까지 읽지는 않았다
- EXAMPLE 두 번째 질문의 말 수(2 + 4 + 10 = 16)가 1단계 「뽑은 말 12개」와 맞는지 — 기간으로 잘린 말과 묶인 말 수를 문서만으로는 알 수 없어 맞춰 보지 못했다
- EXAMPLE 의 「전화번호가 든 말 (11:02)」이 오전 11시인지, 밤 11시 02분(`E:122` 의 「밤 11시 02분」)을 잘못 적은 것인지
- `install.ps1` 의 동작, 다시 설치할 때 고친 SKILL.md 가 정말 `skills-backup` 으로만 가는지는 `install.sh` 주석과 `cp -R` 줄만 보고 적었고 돌려 보지 않았다
