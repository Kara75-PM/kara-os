## 3. 한 것 · 못 한 것 · 확인 안 한 것

### 한 것

- `skills/sns-writing/` 의 README.md · SKILL.md · EXAMPLE.md · references 4개를 **처음부터 끝까지** 읽었습니다
- 어긋남을 확인하려고 `templates/` 3개 · `CHANGES.md` 를 읽고, `install.sh` 의 옛 판 처리 부분과 옆 스킬 두 개의 머리말(`description`)을 봤습니다
- 어긋나는 곳 **35곳**을 `파일:줄` 과 함께 표로 정리했습니다 (🔴 3 · 🟡 15 · ⚪ 17)
- 불러야 하는 말 10개, 부르면 안 되는 말 5개, 경계가 애매한 말 3개와 각각의 맞는 반응을 적었습니다
- EXAMPLE 의 본문·메모 글자 수는 `wc -m` 으로 직접 셌습니다 (공백·줄바꿈 제외)
- **`skills/` 안의 파일은 하나도 고치지 않았습니다.** 바뀐 파일은 `docs/review/sns-writing.md` 하나입니다

### 못 한 것

- **스킬을 실제로 불러 보지 못했습니다.** 2장의 「맞는 반응」은 문서를 읽고 적은 **기대값**이지, 돌려서 나온 결과가 아닙니다. 클로드가 정말 그 말에 이 스킬을 부르는지는 모릅니다
- 어긋난 곳을 **고치지 않았습니다** — 요청대로입니다. 어느 쪽으로 맞출지는 정해 드리지 않았습니다 (1장의 「왜 걸리나」는 판단 근거일 뿐)
- PR 은 열기만 했고 **합치지 않았습니다**

### 확인 안 한 것

- `channel-instagram.md` 의 HTML 골격을 브라우저로 열어 PNG 저장이 되는지 돌려 보지 않았습니다 (Pretendard 글꼴을 다른 곳에서 불러와 html2canvas 로 찍을 때 글꼴이 빠지는지 등)
- 인스타 캡션 링크가 눌리지 않는다, 스레드 한 칸 최대 500자, 해시태그 10~15개 같은 **플랫폼 사실**이 지금도 맞는지 찾아보지 않았습니다
- `install.sh` 를 실제로 돌려 「문서 11개」가 나오는지, 「예제를 지금 열어볼까요?」가 뜨는지 보지 않았습니다 (파일 수는 세어서 11개인 것만 확인)
