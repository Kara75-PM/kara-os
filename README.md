# 카라 OS

**내 이야기로 도는 SNS 도구 모음.**
방식은 공개하고, 재료는 각자 자기 컴퓨터에 둡니다.

| 스킬 | 답하는 것 |
|---|---|
| **`sns-writing`** | 글을 **어떻게 쓰나** — 스레드·인스타 캐러셀 |
| **`source-to-lead`** | 그 글이 사람을 **어디로 보내나** — 채널 배정·링크 자리·UTM·QR |

**따로 써도 됩니다.** 각 스킬은 다른 스킬이 없어도 혼자 돕니다.

---

## 무엇이 다른가

보통의 글쓰기 스킬에는 **만든 사람의 맥락이 박혀 있습니다.** 그 사람의 회사, 그 사람의 프로젝트.
그래서 남이 받아 쓰면 핏이 안 맞고, 매번 걷어내야 합니다.

**이 스킬들은 「만드는 방식」과 「쓰는 사람의 재료」를 아예 분리했습니다.**

| | 어디에 | 공개되나 |
|---|---|---|
| **만드는 방식** — 훅 유형, 채널 규격, 링크 자리 | 스킬 폴더 안 | ✅ 공개 |
| **내 재료** — 내가 누구인지, 겪은 일, 내 어투 | **스킬 폴더 바깥**의 재료 폴더 | ❌ 내 컴퓨터에만 |

## 설치

### 맥 · 리눅스

```bash
D=$(mktemp -d) && git clone --depth 1 https://github.com/Kara75-PM/kara-os.git "$D" && bash "$D/install.sh"
```

### 윈도우 (PowerShell)

```powershell
$d = Join-Path $env:TEMP ("kara-os-" + [guid]::NewGuid()); git clone --depth 1 https://github.com/Kara75-PM/kara-os.git $d; powershell -ExecutionPolicy Bypass -File "$d\install.ps1"
```

### 지금 프로젝트에만 넣고 싶다면

맥은 `bash "$D/install.sh" .` · 윈도우는 `... -File "$d\install.ps1" -Local`

### 확인

```bash
find ~/.claude/skills/sns-writing -type f     # 파일 10개
find ~/.claude/skills/source-to-lead -type f  # 파일 9개
```

### 🔴 스킬을 처음 써 보신다면 — **클로드 코드를 한 번 껐다 켜세요**

평소에는 넣는 즉시 잡힙니다. **딱 한 경우만 예외입니다.**

```
~/.claude/skills 폴더가 원래 없었다면 → 설치할 때 처음 생깁니다 → 다시 켜야 합니다
```

설치했는데 안 불리면 **십중팔구 이것입니다.** 고장이 아닙니다.

## 이 스킬이 하는 일 / 안 하는 일

낯선 사람의 컴퓨터에 무언가를 넣는 쪽의 최소한이라 적어둡니다.

| | |
|---|---|
| **파일을 어디에 쓰나** | 스킬 폴더, 그리고 **물어본 뒤** 작업 폴더의 재료 폴더. 그 밖에는 없습니다 |
| **인터넷에 뭘 보내나** | 없습니다. 설치할 때 파일을 받는 것이 전부입니다 |
| **뭘 지우나** | 아무것도 안 지웁니다. (덮어쓸 때만 물어보고 덮어씁니다) |
| **돈이 드나** | 안 듭니다 |
| **프로그램을 깔거나 설정을 바꾸나** | 안 합니다 |
| **내 개인 이야기는 어디에** | **내 컴퓨터의 재료 폴더 안에만.** 스킬 폴더 바깥이라 같이 안 올라갑니다 |

> 🔴 **단, 작업 폴더가 깃 저장소면** 재료 폴더가 커밋될 수 있습니다.
> 그래서 스킬이 재료 폴더를 만들 때 **`.gitignore` 에 `*-private/` 를 넣을지 물어봅니다.**

## 처음 쓰는 법 — 30분

### 1. 재료 폴더를 만듭니다 (스킬한테 시키세요)

```
재료 폴더 만들어줘
```

🔑 **직접 `mkdir` 하지 마세요.** 어디서 실행하느냐에 따라 엉뚱한 곳에 생깁니다.
스킬은 지금 작업 폴더를 알고 있어서 틀릴 수가 없습니다.

만들어지면 `templates/` 의 **견본이 채워진 채로** 복사됩니다. 지우고 내 걸로 바꾸면 됩니다.

### 2. 소재를 한 줄 적습니다

`material-stash.md` 에 오늘 겪은 일을 한 줄. **다듬지 마세요.**

### 3. 글을 씁니다

```
스레드 글 써줘
```

훅 후보 3개를 줍니다. 고르면 전체를 씁니다.

### 4. 어디로 보낼지 설계합니다

```
이 소재로 콘텐츠 만들어줘. 신청은 (주소)로 받을 거야
```

목적지부터 정하고, 몇 편으로 펼칠지·어느 채널에·링크는 어디에까지 표로 냅니다.

## 구성

```
kara-os/
  install.sh · install.ps1      맥·윈도우 설치기
  skills/
    sns-writing/                SKILL.md · README · CHANGES · templates 3 · references 4
    source-to-lead/             SKILL.md · README · templates 4 · references 3
```

> **`references/` 가 없어도 스킬은 돕니다.** `SKILL.md` 안에 「참고 요약」이 들어 있습니다.
> 다만 실제 예시 문장과 HTML 골격이 빠지므로 **통째로 받는 쪽을 권합니다.**
