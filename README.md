# 카라 OS

**클로드(Claude)에게 SNS 글쓰기를 시킬 때 쓰는 도구 두 개입니다.**

내 이야기를 한 번만 적어두면, 그다음부터는 매번 설명하지 않아도 내 말투로 글을 써 줍니다.

---

## 무엇을 해 주나

### 도구 1 · `sns-writing` — 글을 씁니다

클로드에게 이렇게 말하면 됩니다.

```
스레드 글 써줘
```

그러면 클로드가 이렇게 움직입니다.

```
1. 어디에 올릴 건지 묻습니다        (스레드? 인스타?)
2. 무슨 이야기를 쓸 건지 정합니다
3. 첫 문장 후보를 3개 줍니다        ← 여기서 고르시면 됩니다
4. 전체를 씁니다                   그대로 복사해서 올릴 수 있는 모양으로
```

### 도구 2 · `source-to-lead` — 그 글이 사람을 어디로 보낼지 정합니다

```
이 이야기로 콘텐츠 만들어줘. 신청은 (내 신청 페이지 주소)로 받을 거야
```

그러면 이런 표를 만들어 줍니다.

```
언제      어디에      무슨 글         링크
9/10     스레드      내 이야기        없음
9/11     인스타      정리해서 보여줌   프로필에
9/13     스레드      결과 알림        신청 페이지 (짧게 줄인 주소)
```

**왜 링크가 어떤 글엔 없냐면** — 매 글마다 링크를 붙이면 사람들이 그 계정을 광고로 봅니다.
그래서 **믿게 만드는 글 두 편에 보내는 글 한 편** 비율로 짭니다.

**둘은 따로 써도 됩니다.** 하나만 설치해도 잘 돕니다.

---

## 다른 글쓰기 도구와 뭐가 다른가

남이 만든 글쓰기 도구를 받아 쓰면 **그 사람 이야기가 안에 박혀 있습니다.**
그 사람 회사 이름, 그 사람이 하던 일, 그 사람 말투. 그래서 쓸 때마다 지워야 합니다.

**이 도구는 그 둘을 아예 갈라놓았습니다.**

| | 어디에 있나 | 남이 볼 수 있나 |
|---|---|---|
| **쓰는 방법** — 첫 문장 잡는 법, 글자 수, 링크 자리 | 도구 폴더 안 | ✅ 봐도 됩니다 |
| **내 이야기** — 내가 누구인지, 겪은 일, 내 말투 | **도구 폴더 바깥의 「재료 폴더」** | ❌ 내 컴퓨터에만 |

그래서 **내 개인 이야기가 인터넷에 안 올라가고**, 남이 이 도구를 받아도 **자기 이야기로 돕니다.**

---

## 안전한가요

남이 만든 걸 내 컴퓨터에 넣는 건 조심스러운 일입니다.
그래서 **이 도구가 무엇을 하고 무엇을 안 하는지** 미리 적어둡니다.

| 궁금한 것 | 답 |
|---|---|
| **내 컴퓨터에 뭘 만드나요?** | 도구 폴더, 그리고 **물어본 다음에** 「재료 폴더」. 그 밖엔 없습니다 |
| **인터넷으로 뭘 보내나요?** | **아무것도 안 보냅니다.** 설치할 때 파일을 받아오는 게 전부입니다 |
| **뭘 지우나요?** | **아무것도 안 지웁니다.** 같은 이름이 이미 있으면 물어본 뒤에만 덮어씁니다 |
| **돈이 드나요?** | 안 듭니다 |
| **프로그램을 깔거나 설정을 바꾸나요?** | 안 합니다 |
| **내 개인 이야기는 어디 있나요?** | **내 컴퓨터의 「재료 폴더」 안에만** 있습니다 |

### 🔴 딱 하나 조심할 것

작업하는 폴더가 **깃(git)으로 관리되는 폴더**라면, 「재료 폴더」가 **딸려 올라갈 수 있습니다.**

> 깃(git)이 뭔지 모르시면 신경 안 쓰셔도 됩니다. 도구가 알아서 확인하고 물어봅니다.

도구가 「재료 폴더」를 만들 때 **이렇게 물어봅니다.**

```
이 폴더는 깃으로 관리되고 있습니다.
지금 작업 폴더의 .gitignore 에 한 줄을 더할까요? (없으면 새로 만듭니다)

  *-private/
```

> **저장소 뿌리가 아니라 「지금 작업 폴더」에 넣습니다.** 뿌리 파일은 같이 쓰는 사람들 것이라서요.
> 이미 같은 줄이 있으면 아무것도 안 합니다. 넣은 뒤 **정말 막혔는지 확인해서 보여줍니다.**

**「네」라고 하시면 됩니다.** 그 한 줄이 내 이야기가 인터넷에 올라가는 걸 막습니다.

## 설치하기

### 먼저 확인할 것

- **클로드 코드(Claude Code)** 가 깔려 있어야 합니다
- **깃(git)** 이 깔려 있어야 합니다 — 없으면 `git` 이라고 쳤을 때 "명령을 찾을 수 없음"이 나옵니다

### 맥 · 리눅스

터미널에 이 한 줄을 붙여넣고 엔터를 누르세요.

```bash
D=$(mktemp -d) && git clone --depth 1 https://github.com/Kara75-PM/kara-os.git "$D" && bash "$D/install.sh"
```

### 윈도우

**PowerShell** 을 열고 이 한 줄을 붙여넣으세요.

```powershell
$d = Join-Path $env:TEMP ("kara-os-" + [guid]::NewGuid()); git clone --depth 1 https://github.com/Kara75-PM/kara-os.git $d; if ($LASTEXITCODE -eq 0) { powershell -ExecutionPolicy Bypass -File "$d\install.ps1" } else { Write-Host "[중단] 받기에 실패했습니다. git 이 깔려 있는지 확인하세요." -ForegroundColor Red }
```

### 잘 됐는지 확인

**맥 · 리눅스**

```bash
find ~/.claude/skills/sns-writing -name '*.md' | wc -l      # 10 이 나오면 성공
find ~/.claude/skills/source-to-lead -name '*.md' | wc -l   # 9 가 나오면 성공
```

**윈도우 (PowerShell)**

```powershell
(Get-ChildItem -Recurse -File -Filter *.md "$env:USERPROFILE\.claude\skills\sns-writing").Count      # 10
(Get-ChildItem -Recurse -File -Filter *.md "$env:USERPROFILE\.claude\skills\source-to-lead").Count   # 9
```

**숫자가 10 과 9 로 나오면 성공입니다.**

### 🔴 안 불릴 때 — 십중팔구 이것입니다

**클로드 코드를 껐다 켜 보세요.**

도구를 처음 설치하는 분은 `.claude/skills` 라는 폴더가 **이번에 처음 생깁니다.**
클로드 코드는 켜질 때 그 폴더를 찾는데, 켜질 당시엔 없었으니 못 봅니다.
**껐다 켜면 그때 찾습니다.** 고장이 아닙니다.

### 지금 프로젝트에서만 쓰고 싶으면

맥은 맨 끝에 `--local`, 윈도우는 `-Local` 을 붙이세요.

```bash
D=$(mktemp -d) && git clone --depth 1 -q https://github.com/Kara75-PM/kara-os.git "$D" && bash "$D/install.sh" --local
```

**이때는 확인 명령도 달라집니다** — 홈이 아니라 **지금 폴더**를 봅니다.

```bash
find ./.claude/skills -name '*.md' | wc -l      # 문서 19개 (둘 다 깔았을 때)
```

### 하나만 깔고 싶으면 — 골라서 설치할 수 있습니다

받은 폴더 안에서 이렇게 하시면 됩니다.

**각각 통째로 붙여넣으시면 됩니다.** 앞부분은 다 같고 **맨 끝만** 다릅니다.

```bash
# 뭐가 있는지 보기만 (아무것도 설치 안 함)
D=$(mktemp -d) && git clone --depth 1 -q https://github.com/Kara75-PM/kara-os.git "$D" && bash "$D/install.sh" --list
```
```bash
# sns-writing 만
D=$(mktemp -d) && git clone --depth 1 -q https://github.com/Kara75-PM/kara-os.git "$D" && bash "$D/install.sh" sns-writing
```
```bash
# 전부
D=$(mktemp -d) && git clone --depth 1 -q https://github.com/Kara75-PM/kara-os.git "$D" && bash "$D/install.sh" --all
```

**아무 것도 안 붙이고 실행하면 목록을 보여주고 번호로 고르게 합니다.**
윈도우는 `-List` · `-All` 또는 스킬 이름을 붙이시면 됩니다.

> 나중에 스킬이 늘어도 **명령은 그대로**입니다. 목록에 자동으로 뜹니다.

### 같은 이름이 이미 있으면

**지우지 않습니다.** 허락을 받은 뒤 `<이름>.old-20260909-172506` 처럼 **날짜와 시각을 붙여 옆에 치워둡니다.**
잘못됐으면 그 폴더 이름만 되돌리면 원래대로 돌아갑니다.
`.old-` 폴더는 자동으로 안 없어지니, 필요 없어지면 직접 지우세요.

## 처음 써보기 — 20분

### 1. 「재료 폴더」를 만듭니다

클로드에게 이렇게 말하세요.

```
재료 폴더 만들어줘
```

> 🔑 **직접 폴더를 만들지 마세요.** 위치가 조금만 달라도 도구가 못 찾습니다.
> 클로드는 지금 어느 폴더에서 일하는지 알고 있어서 **틀릴 수가 없습니다.**

만들어지면 **예시가 채워진 파일**이 들어 있습니다. 지우고 내 이야기로 바꾸면 됩니다.
어느 도구가 만드느냐에 따라 **3개(`sns-writing`) 또는 4개(`source-to-lead`)** 입니다.

| 파일 | 뭘 적나 |
|---|---|
| `who-i-am.md` | 내가 누구인지 한두 줄 |
| `material-stash.md` | 겪은 일을 한 줄씩 |
| `my-voice.md` | 내 말투. **처음엔 비워두세요** — 글을 쓸수록 도구가 채웁니다 |

### 2. 겪은 일을 한 줄 적습니다

`material-stash.md` 를 열어 오늘 있었던 일을 한 줄 적으세요. **다듬지 마세요.**

```
- 2026-09-09  스터디를 열었더니 아홉 시간 만에 두 명이 왔다
```

**이게 쌓이면 "뭘 쓰지"가 없어집니다.**

### 3. 글을 씁니다

```
스레드 글 써줘
```

첫 문장 후보 3개를 줍니다. 고르면 전체를 씁니다.

### 4. 올린 뒤에

올린 글을 고쳐서 올리셨다면, 그 사실을 클로드에게 알려주세요.
**뭘 바꾸셨는지 보고 `my-voice.md` 에 한 줄 쌓아둡니다.** 다음 글부터 그 말투로 씁니다.

## 낱말 풀이

이 문서와 도구 안에 나오는 말들입니다.

| 말 | 뜻 |
|---|---|
| **스킬 (skill)** | 클로드에게 "이런 일은 이렇게 해라"라고 미리 적어둔 설명서 묶음 |
| **클로드 코드** | 컴퓨터에서 클로드를 쓰는 프로그램. 파일을 읽고 쓸 수 있습니다 |
| **재료 폴더** | 내 이야기(내가 누구인지·겪은 일·내 말투)를 적어두는 폴더. **도구 폴더 바깥**에 둡니다. 실제 폴더 이름은 **`kara-os-private/`** 입니다 |
| **첫 문장 (훅)** | 스레드의 첫 칸, 인스타의 첫 장. **여기서 볼지 말지가 갈립니다** |
| **캐러셀** | 인스타에서 **옆으로 넘기는 여러 장짜리** 게시물 |
| **칸** | **스레드 게시물 한 조각.** 스레드는 글을 여러 칸으로 이어 붙여 올립니다 |
| **장** | **캐러셀 카드 한 장.** 옆으로 넘기는 그 한 장입니다 |
| **편** | **글 한 편.** 「1편·2편」은 회차를 뜻합니다 (내 편/네 편의 「편」이 아닙니다) |
| **깃 저장소 안에 있다** | 그 폴더가 **깃으로 관리되고 있다**는 뜻입니다. 「깃 저장소가 아니다」가 아닙니다 |
| **꼬리표 (UTM)** | 링크 뒤에 붙이는 표시. `?utm_source=threads` 처럼 붙여두면 **어디서 온 사람인지** 알 수 있습니다 |
| **QR** | 네모난 점무늬. 폰 카메라로 비추면 그 주소로 갑니다. 전단·명함에 씁니다 |
| **CTA** | *Call To Action* — **「무엇을 하면 되는지」 안내.** *"프로필 링크로 오세요"* 같은 한 줄 |
| **HTML** | 웹페이지를 만드는 글자 파일. 카드 이미지를 만들 때 씁니다 |
| **PNG** | 그림 파일 형식. 인스타에 올리는 카드가 이 형식입니다 |
| **깃 (git)** | 파일이 바뀐 내역을 기록해 두는 프로그램. 개발할 때 씁니다 |
| **ExecutionPolicy Bypass** | 윈도우가 기본으로 막는 스크립트 실행을 **이 한 번만** 허용하는 설정입니다. 설정이 영구히 바뀌지는 않습니다 |
| **저장소** | 인터넷(깃허브)에 올려둔 내 폴더. 남에게 주소만 주면 받아갈 수 있습니다 |
| **터미널** | 명령을 글자로 쳐서 컴퓨터를 시키는 창. 맥은 「터미널」, 윈도우는 「PowerShell」 |

## 안에 뭐가 들어 있나

```
kara-os/
  install.sh        맥·리눅스에서 설치할 때 실행되는 파일
  install.ps1       윈도우용
  skills/
    sns-writing/      글 쓰는 도구
    source-to-lead/   어디로 보낼지 정하는 도구
```

각 도구 폴더 안은 이렇습니다.

| 이름 | 무엇 |
|---|---|
| `SKILL.md` | **클로드가 읽는 설명서.** 사람이 안 읽어도 됩니다 |
| `README.md` | 사람이 읽는 설명 |
| `templates/` | **예시가 채워진 견본.** 「재료 폴더」를 만들 때 여기서 복사됩니다 |
| `references/` | 더 자세한 참고 자료 |

> **`references/` 가 없어도 도구는 돕니다.** `SKILL.md` 안에 핵심 요약이 들어 있습니다.
> 다만 예시 문장이 빠지므로 **통째로 받으시는 게 좋습니다.**

## 만든 사람과 출처

`sns-writing` 은 셀피시클럽 스폰지클럽 3기 스킬러스 모임에서 공유된
**노슈니(오수인)님의 `threads-writing`** 을 바탕으로 고쳐 만든 것입니다.
무엇을 어떻게 바꿨는지는 `skills/sns-writing/CHANGES.md` 에 적혀 있습니다.

`source-to-lead` 는 처음부터 새로 만든 것입니다.

⚠️ **라이선스(남이 이걸 어디까지 쓸 수 있는지)는 아직 안 정했습니다.**
원본에 표기가 없어 확인 중입니다. 정해지면 여기에 적겠습니다.
